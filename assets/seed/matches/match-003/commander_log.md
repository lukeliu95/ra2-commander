1. 出生点互换：我方 (71,118)，AI (135,80)；AI 从我方东北入口 (84–88,106–112) 进入。
2. **阵营是苏军**（档案两局都是盟军）。建筑：NACNST/NAPOWR/NAHAND/NAREFN/NAWEAP/NALASR(0:54)/NARADR(≤2:15)/NADEPT(≤3:41)，6:23 前已有作战实验室（没侦察到，由天启推断）。
3. 波次节奏（全部在公平视野下观察）：
   - 0:42 军犬骚扰（档案 1:03–1:40，更早）；
   - 第 1 波 1:20 出门，约 20 E2 纯步兵，1:24–1:36 交战；
   - 第 2 波 2:38 出门，21 E2+3 HTNK+1–2 HTK（约 5300–5500），2:50–3:14 交战；
   - 第 3 波 4:17 出门，11 E2+3 HTNK+2 HTK+1 V3（约 5500），4:26–5:43 交战；

4. 单个 E2/HTK 反复去打 (86,106)/(102,99) 一带的矿车，把我方部队引出碉堡范围。

**执行层问题**
1. plan 改动不取消在建/已排产项（战车工厂、NASAM、碉堡、电厂都验证过）。推测：runtime 只在排产时看 plan，没有"队列里有 plan 不再需要的项就取消"的逻辑。资金紧张时指挥官没有止血手段。
2. 防空反射把 V3 导弹 V3ROCKET 当成空军（4:30），自动排产 NASAM；7:06 在 aaDef=0 时又排产一次。推测：空中单位判断没有排除导弹/弹体类型，而且反射的最低值会覆盖 plan。
3. "矿车被攻击"迎击反射不受 threatRadius 限制，全军去远处追单个单位，被随后的主力吃掉（4:26、6:31）。建议加一个迎击最大距离，比如离最近防御塔 ≤ 10 格，或者只派一部分兵。
4. apply 从调用到生效约 10 游戏秒（3:29 调用，3:40 出现 plan 事件）。一部分是 agent 往返延迟，紧急调整要预判提前。
5. 敌方 visibleArmy 在侦察犬死后仍长时间显示敌方家门口的旧位置（1:36–2:30 static 在 (130–133,83–85)），疑似残留记忆而不是实时可见，可能误导 trend 判断。
